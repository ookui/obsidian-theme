# Tana Inspired

A dark-first Obsidian theme inspired by Tana Outliner's quiet, structured workspace aesthetic, with a calm light mode for daytime writing.

## Install

Place this folder in your vault at:

```text
.obsidian/themes/Tana Inspired/
```

Then open Obsidian, go to **Settings -> Appearance -> Themes**, and select **Tana Inspired**.

## Design Notes

- Near-black dark mode with graphite surfaces and luminous green accents.
- Warm off-white light mode with the same semantic accent family.
- Outliner-friendly details: subtle indentation guides, crisp bullets, compact navigation, and pill-like tags.
- No external fonts or assets, so the theme works offline and stays portable.

## Optional Style Settings

The theme exposes a small Style Settings block for users who have the Style Settings community plugin installed. The theme works normally without it.
